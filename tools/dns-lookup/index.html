DNS Lookup

Query live DNS records for any domain.

Enter a domain and choose a record type.

What this tool checks

DNS records control where websites, email and verification services point. Use A/AAAA for IP addresses, MX for mail servers, NS for nameservers and TXT for verification or email security records.

Live data

This tool sends a DNS-over-HTTPS query to Google Public DNS. Results can change as DNS records propagate.
