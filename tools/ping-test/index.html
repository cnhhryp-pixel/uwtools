Enter a domain to begin.

Measures browser HTTPS request timing, not ICMP ping.

Browser latency vs ICMP ping

Web browsers cannot send raw ICMP ping packets. This tool measures HTTPS request timing instead. Because the request uses browser networking, the result is only an approximate browser-to-site latency indicator.

Why results vary

DNS, TLS setup, CDN location, browser cache and your current network can all affect the measured time.
