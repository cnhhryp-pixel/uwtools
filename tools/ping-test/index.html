Measure approximate HTTPS response time from your current browser.

Browser latency vs ICMP ping

Web browsers cannot send raw ICMP ping packets. This tool measures HTTPS request timing instead, which is useful for a quick browser-to-site latency check.

Why results vary

DNS, TLS setup, CDN location, browser cache and your current network can all affect the measured time.
