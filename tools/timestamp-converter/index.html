Seconds or milliseconds?

Unix timestamps are commonly stored as seconds since 1970-01-01 UTC. JavaScript and many APIs also use milliseconds. This tool detects 13-digit millisecond values automatically.

UTC vs local time

The same timestamp represents one instant. UTC and your browser's local time are two different displays of that instant.
