HTML Escape / Unescape

Convert HTML-sensitive characters to entities or decode them back to readable text.

Converted text will appear here.

Works locally in your browser.

What gets escaped?

HTML escaping converts characters such as <, >, &, quotes and apostrophes into entities so code can be displayed safely as text.

When to use it

Use escaping when embedding code samples or displaying user-provided text inside HTML. Unescaping reverses common HTML entities.
