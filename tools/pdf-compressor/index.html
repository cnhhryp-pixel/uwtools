PDF Compressor

Reduce image-heavy PDF size with browser-based raster compression.

Choose a PDF to begin.

How this compressor works

Each page is rendered as a compressed JPG and rebuilt into a PDF. This is especially useful for scanned or image-heavy PDFs.

Important limitation

The compressed output is rasterized, so selectable text, links and vector elements are flattened. For text-heavy PDFs, the result may not be smaller.

Privacy

The document is processed locally in your browser.
