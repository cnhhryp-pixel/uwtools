How this compressor works

Each PDF page is rendered as an image, recompressed as JPEG and rebuilt into a new PDF. This works best for scanned or image-heavy documents.

Important limitation

The output is rasterized. Selectable text, vector graphics, links and form fields are flattened.

Not always smaller

Text-heavy PDFs may already be highly optimized, so the compressed output can occasionally be the same size or larger.
