URL Encoder / Decoder

Encode text for URL components or decode percent-encoded text.

Uses encodeURIComponent and decodeURIComponent.

URL encoding

Percent-encoding converts characters that are unsafe or reserved in a URL component into sequences such as %20.

Component vs full URL

This tool encodes URL components. Encoding an entire URL would also escape characters such as : and /, which is usually not what you want.
