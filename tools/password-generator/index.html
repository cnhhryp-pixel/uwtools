How secure generation works

This tool uses crypto.getRandomValues(), the browser's cryptographically secure random number generator.

Password length matters

Longer passwords generally provide more entropy. A password manager can store long unique passwords for each account.

Privacy

Generated passwords are not sent to a server by this tool.
