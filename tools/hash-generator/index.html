Which hash should I use?

SHA-256 is widely used and usually the best default. SHA-384 and SHA-512 produce longer digests.

Hashes are one-way

A cryptographic hash is designed to be one-way. It is not encryption and cannot be decoded back into the original input.

Privacy

Hashing is performed with the browser Web Crypto API.
